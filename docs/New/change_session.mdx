# How to Change Session

You can change Session easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right side, click on the Settings icon.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/change-session.png)

3. A page will open. Update the session from the dropdown menu.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/change-session-2.png)
    
4. Click on Save to apply the changes.
