# How to Add Bus Stops

You can add bus stops easily using UdyogX.

## Stepwise guide

1. **Log in** to the software by entering your **username** and **password**.
2. In the left sidebar, hover over Transport and click on Stops from the submenu.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/how-to-add-stops.png)

3. The Stops page will open. Enter the required stop details.
4. Click on Submit to save the details.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/add-bus-stops-2.png)
    
5. The bus stops will be successfully added.
