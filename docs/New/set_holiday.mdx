# How to Set Holiday in Attendance

You can set holidays easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right side, click on the Settings icon.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/set-holiday.png)

3. A page will open. Locate the section Holidays this Session, click on the field, and choose the date(s). Multiple holidays can be selected by separating them with commas.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/set-holiday-2.png)
    
4. Click on Save to apply the changes.
