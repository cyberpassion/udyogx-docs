# Set Principal Signature

You can set principal's signature easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the Settings icon.
3. A dropdown menu will appear. Scroll down and click on Upload Settings.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/set-principal-signature.png)

4. A new page will open. Select Principal Signature and click on the blue upload icon to upload the signature file.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/set-principal-signature-2.png)
