# How to Change Examresult Card Format

You can change Examresult card format easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Exam.
3. A submenu will appear. Click on Settings.
4. Under the heading EOY Report Card Format, select the desired format from the dropdown menu.
5. Click on Save to apply the changes.
