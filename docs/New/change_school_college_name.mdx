# How to Change Name of School/College

You can change name of School/College easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Student.
3. A dropdown will appear. Hover on Settings, a dropdown will appear, click on Basic Settings.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/change-name-of-schoolcollege.png)

4. Make the required changes and click on Save.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/change-name-of-schoolcollege-2.png)
