# How to Get API Key

You can get API Key easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the User icon.
3. From the dropdown menu, click on "Get API".

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/get-API-key.png)
    
4. The API key will be shown, click on the copy button to copy the API key.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/get-api-key-2.png)
