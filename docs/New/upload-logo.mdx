# Upload Logo

You can update logo easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the Settings icon.
3. Scroll down and click on Upload Settings.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/upload-logo.png)

4. A page will open. Select Logo and click on the blue upload symbol.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/upload-logo-2.png)

5. A dialog box will appear. Select the logo file and click Open.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/upload-logo-3.png)

6. The logo will be uploaded successfully.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/upload-logo-4-.png)
