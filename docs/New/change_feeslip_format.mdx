# How to Change Fee Slip Format

You can change Fee Slip format easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Student.
3. A submenu will appear. Hover over Fee Settings, then from the next submenu, click on Fee Settings.
4. Select the desired template from the Fee Slip Template dropdown and click on Save.
