# How to Get Support Pin

You can get Support Pin easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the User icon.
3. From the dropdown menu, click on "Get Support Pin".

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/get-support-pin.png)
    
4. The Support Pin will be shown, click on the copy button to copy the API key.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/get-support-pin-2.png)
