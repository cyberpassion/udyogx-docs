# Offer

You can see offers easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the User icon.
3. From the dropdown menu, click on "Offers".

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/offers.png)
    
4. A page will open showing all the offers.
