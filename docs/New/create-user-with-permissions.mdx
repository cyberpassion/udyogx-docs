# How to Create User With Permissions

You can create user with permissions easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the User icon.
3. A dropdown will appear. Hover over User.
4. Another dropdown will appear. Click on Create User.
5. Fill in the required user details and assign the necessary permissions.
6. Click on Save to create the user.
