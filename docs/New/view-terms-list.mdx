# How to Add New Term

You can view terms list easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the User icon.
3. From the dropdown menu, hover over Term.
4. A secondary dropdown will appear; click on View Terms List.
5. A page will open showing the terms list.
