# How to Sync Tables

You can sync tables easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the User icon.
3. From the dropdown menu, click on "Sync Tables".

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/sync-tables.png)

4. A page will open telling the tables are synced.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/sync-tables-2.png)
