# How to Add New Term

You can add new terms easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the User icon.
3. From the dropdown menu, hover over Term.
4. A secondary dropdown will appear; click on Add New Term.

   ![](https://learn.udyogx.in/wp-content/uploads/2025/08/add-term-.png)

5. A new page will open; fill in the required information and click Submit.

   ![](https://learn.udyogx.in/wp-content/uploads/2025/08/add-term-2.png)
