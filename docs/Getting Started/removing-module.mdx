# How to Remove Module

You can remove modules easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the Profile icon and click on Add Module.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/remove-module-1.png)

3. A page will open displaying all modules. For the module you want to remove, click on the arrow button on the right side, then hover over Subscription and click on Remove.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/remove-module-2.png)

4. A popup will appear asking for confirmation. Click on Confirm.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/remove-module-3.png)
    
5. The selected module will be removed.
