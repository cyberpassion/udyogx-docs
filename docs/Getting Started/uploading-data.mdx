# How to Upload Data

You can upload data easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the Profile option. A submenu will appear. Hover over Profile, then from the submenu, click on Upload Docs.
3. Select the type of data you want to upload.
4. Click on the blue Upload icon.
5. A dialog box will appear. Select the file and click on Open.
6. The file will be uploaded successfully.
