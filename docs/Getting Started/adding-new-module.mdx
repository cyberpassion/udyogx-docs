# How to Add New Module

You can add new modules easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the top right corner, hover over the Profile icon. A submenu will appear. Click on Add Module.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Add-Module-1.png)

3. A page will open displaying all available modules. For the module you want to purchase, click on the arrow on the right side, hover over Subscription, and then click on Add.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Add-Module-2.png)

4. A confirmation page will appear. Click on Pay.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Add-Module-3.png)

5. Select the desired payment method and click on Pay Now.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Add-Module-4.png)

6. A confirmation page will appear indicating successful payment.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Add-Module-5.png)

7. Go to the software dashboard. The newly added module will now be visible on the left sidebar.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Add-Module-6.png)
