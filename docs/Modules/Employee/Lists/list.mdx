# Employee List

With udyogX you can easily view list an employee. To do this first log in to the software entering your username and password.

## Stepwise Guide

1. In the left sidebar menu, go to ‘Employee > Employee List’.

   ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Employee-List.png)
   
2. Alternatively you can also search employee in the searchbar at the top.
3. In the list that appears, find the Employee, and hover on the filter arrow located next to it.
4. The view list will appear on the page.
