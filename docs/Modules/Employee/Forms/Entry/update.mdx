# Update Employee

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Employee > Employee List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Employee-List.png)

2.  In the list, find the employee's name, and click on the filter arrow located next to it.
3.  In the dropdown menu select 'Profile > Edit Profile'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Update-Employee.png)
    
4.  The entry page will open where you can make suitable changes as required.
5.  After making the changes click on 'Save' button.
6.  A confirmation modal would appear on successful submission.
