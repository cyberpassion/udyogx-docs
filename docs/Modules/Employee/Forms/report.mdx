# Report

Follow these steps to View Employee Report in UdyogX.

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Employee > View Report'.

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/2024-09-14_16-27-18-300x150.png)
2.  Select the filters as per your choice
3.  From the list on the right, select the particulars you wish to include in your report and then click on Save.![](https://learn.udyogx.in/wp-content/uploads/2022/06/Employee-Report-page-300x200.png)
4.  The report will now be displayed on the screen. You can print it by clicking on print button or CTRL+P
