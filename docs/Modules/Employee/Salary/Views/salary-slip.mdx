# Salary slip

Follow these steps to View Employee salary History in UdyogX.

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Employee > Employee List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Employee-List.png)

2.  In the list, find the Employee's name, and click on the filter arrow located next to it.
3.  In the dropdown menu, select 'Salary > View History'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Employee-Salary-Slip.png)
    
4.  A page with history details will open with all the transactions.
5.  You can print the report by clicking CTRL+P or print button.
