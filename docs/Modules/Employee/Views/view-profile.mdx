# View Profile

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Employee > Employee List'.
2.  In the list, find the the employee, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Employee > view Profile'
4.  The profile details will appear on the page.
