# View Details

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Meetings > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Meetings-List.png)

2.  In the list, find the the meetingmanager, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Meetingmanager > View Details'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Meetings-View-Details.png)
    
4.  The details will appear on the page.
