# Settings

1.  Go to 'Settings' in Meetingmanager Module

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Meetings-Settings-1.png)

2.  Make Changes as per your needs
3.  After filling the columns click on 'Save'

    | S.No | Setting Name                     | Description |
    |------|----------------------------------|-------------|
    | 1    | Meeting Manager Heads\*          | In what categories can a meeting entry be entered? Enter category name here. |
    | 2    | Meeting With Individuals\*       | If we want to have a meeting with someone who is not an employee or is working on a temporary basis and their name is not showing in the list, we add their name here. |
    | 3    | Default meeting time (in mts)\*  | We will set the duration of the meeting for how many minutes it lasts. This makes it easier to plan meetings during the day. |
    | 4    | Meeting Start and Ending Time    | You can meet from when to when for the meeting, the timing entry will be right here. |
    | 5    | Columns in Meeting Report        | In the meeting report, which columns are needed, their entries will be made here. |
    | 6    | Send Meeting Confirmation SMS\*  | Do you want to send an SMS for confirming the meeting or not? Select here. |
    | 7    | Template ID                      | Enter the template ID of the SMS to be sent. |
    | 8    | Template                         | Here, an entry will be made for sending SMS. |
