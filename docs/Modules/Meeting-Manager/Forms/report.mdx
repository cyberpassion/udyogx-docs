# Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Meetingmanager > View Report'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Meetings-Report-1.png)

2.  Select the filters of your choice and click on 'View Report'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Meetings-Report-2-1.png)

3.  A page will open with the Report
4.  You can print the report by clicking on print button or CTRL+P
