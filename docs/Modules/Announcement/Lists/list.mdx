# Announcement List

With udyogX you can easily view list an announcement. To do this first log in to the software entering your username and password.

## Stepwise Guide

1.  In the left sidebar menu, go to 'Announcement > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/2024-09-16_16-28-24-1-300x150.png)

2.  Alternatively you can also search announcement in the searchbar at the top.![](https://learn.udyogx.in/wp-content/uploads/2022/06/search-announcement.png)
3.  In the list that appears, find the Announcement, and hover on the filter arrow located next to it.
4.  The view list will appear on the page.
