# View Details

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Announcement > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Announcement-List.png)

2.  In the list, find the the announcement, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Announcement > View Details'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Announcement-View-Details-1.png)

4.  The details will appear on the page. You can print it by clicking on the print button or pressing CTRL+P
