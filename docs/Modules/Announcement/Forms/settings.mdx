# Settings

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Announcement > Settings'. ![](https://learn.udyogx.in/wp-content/uploads/2023/09/Untitled-design-10.png)
2.  Make changes as required and then click on 'Save' button at the bottom. ![](https://learn.udyogx.in/wp-content/uploads/2023/09/Untitled-design-11.png)
