# Update Announcement

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Announcement > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Announcement-List.png)

2.  In the list, find the Announcement , and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Announcement > Edit'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Update-Announcement.png)

4.  The entry page will open where you can make changes
5.  After making the changes click on 'Save' button at the bottom.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Update-Announcement-save-1.png)

6.  A confirmation modal would appear on successful submission.
