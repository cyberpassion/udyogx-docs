# Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Announcement > View Report'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Announcement-View-Report-1.png)

2.  Select ‘Category’, ‘Date’, ‘Appearance’ and ‘Status’ and click on ‘View Report’

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Announcement-View-Report-2.png)

3.  A page will open with the report.
4.  You can print the report by clicking on the print button or pressing CTRL+P
