# Checklist List

With udyogX you can easily view list an checklist. To do this first log in to the software entering your username and password.

## Stepwise Guide

1. In the left sidebar menu, go to ‘Checklist > View List’.

   ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Checklist-List.png)
   
2. Alternatively you can also search checklist in the search bar at the top.
3. In the list that appears, find the Checklist, and hover on the filter arrow located next to it.
4. The view list will appear on the page.
