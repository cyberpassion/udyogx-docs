# Settings

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Checklist > Settings'. 

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Checklist-Settings.png)
    
2.  Make changes as required and then click on 'Save' button at the bottom.
