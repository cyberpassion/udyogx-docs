# Add Checklist

You can add checklist easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. In the **left sidebar menu**, go to **`Checklist > Add New`**.

   ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Add-Checklist.png)

3. A form will open with the following fields:
   - **Checklist Name**: Enter the Checklist Name.
   - **Select Listing**: Select the Listing for the checklist.
   - **Follow Sequence**: Select the Sequence for the checklist.
   - **Description**: Enter the content of the checklist.
4. After filling out the form, click **`Save`**.

   ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Add-Checklist-2.png)
   
5. Upon successful submission, a **confirmation modal** will appear to confirm that the checklist has been added.
