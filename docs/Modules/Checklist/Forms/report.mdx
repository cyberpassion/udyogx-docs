# Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Checklist > Report'.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Checklist-Report-1.png)

2.  Select ‘Select Date’, ‘Select Status’ and click on ‘View’

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Checklist-Report-2-3.png)

3.  A page will open with the report.
4.  You can print the report by clicking on the print button or pressing CTRL+P
