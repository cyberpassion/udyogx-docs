# How to view plan list

You can view plans list easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Subscription. A submenu will appear. Click on View Plans List.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/view-plans-list.png)
    
3. A page will open displaying all the plans.
