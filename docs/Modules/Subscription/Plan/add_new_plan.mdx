# How to add new plan

You can add new plan easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Subscription. A submenu will appear. Click on Add New Plan.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-new-plan.png)

3. A page will open. Enter all the required plan details and click on Save.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-new-plan-2.png)
