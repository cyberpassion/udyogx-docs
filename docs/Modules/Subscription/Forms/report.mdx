# Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Subscription > View Report’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/subscription-report.png)

2.  A filter page will open. Select the 'Plan Category', Plan Name, User Type, Select Status then click 'View Report'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/subscription-report-2.png)
    
3.  The report will now display on the screen.
4.  Click on 'Print' button or press CTRL+P to print the report.
