# Update Subscription

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Subscription > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-subscription.png)

2.  In the list, find the subscription , and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Subscription > Edit'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-subscription-2.png)

4.  The entry page will open where you can make changes.
5.  After making the changes click on 'Save' button at the bottom.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-subscription-3.png)

6.  A confirmation modal would appear on successful submission.
