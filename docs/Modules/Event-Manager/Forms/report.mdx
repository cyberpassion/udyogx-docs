# Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Eventmanager > View Report'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Event-Report-1.png)

2.  Select 'Head' and 'Date'
3.  Click on 'View'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Event-Report-2.png)

4.  A page will open with the report. you can print the report by clicking on print button or pressing CTRL+P
