# Settings

## Stepwise Guide

1.  Go to "Settings" in Event Manager
2.  Make Changes as per your Requirement
3.  Click on "Save"

| S.No | Setting Name                           | Description                                                                 |
|------|----------------------------------------|-----------------------------------------------------------------------------|
| 1    | Send Book Allotment Notification SMS   | Sending SMS notifications when library books are allocated, you need to choose options for that. |
| 2    | Template ID                            | Enter the template ID of the SMS to be sent.                               |
| 3    | Template                               | Here, we will log the entry of the SMS to be sent.                         |
| 4    | Send Book Return Notification SMS      | To send an SMS notification for returning library books, you will need to choose that option. |
| 5    | Template ID                            | Enter the template ID of the SMS to be sent.                               |
| 6    | Template                               | Yes, the SMS you want to send will be entered.                             |
