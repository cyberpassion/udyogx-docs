# Update Event Manager

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Eventmanager > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/2024-09-16_16-05-31-1-300x150.png)

2.  In the list, find the Event's name, and click on the filter arrow located next to it.
3.  In the dropdown menu, Click on 'Eventmanager > Edit'

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/2024-09-16_16-13-37-300x150.png)
    
4.  The entry page will open. Make suitable changes.
5.  After making changes click on 'Save'
6.  A confirmation modal would appear on successful submission.
