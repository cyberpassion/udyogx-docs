# Add Event Manager

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Eventmanager > Add New'.

   ![](https://learn.udyogx.in/wp-content/uploads/2022/06/2024-09-16_16-05-31-300x150.png)

2.  The entry page will open. Fill the details of the event such as 'Event Type', 'Event Date', 'Event Name', 'Event Details'.

   ![](https://learn.udyogx.in/wp-content/uploads/2022/06/2024-09-16_16-08-41-300x150.png)
   
3.  From the list on the right, choose the recipient you would like to invite to the event and click on 'Save'.
4.  A confirmation modal would appear on successful submission.
