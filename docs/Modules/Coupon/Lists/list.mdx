# Coupon List

You can view list easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Subscription. A submenu will appear.
3. Hover over Coupon, then from the next submenu, click on Coupons List.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/coupon-list.png)
    
4. The list of coupons will be displayed.
