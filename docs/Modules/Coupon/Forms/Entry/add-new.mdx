# Add Coupon

You can add new coupons easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Subscription. A submenu will appear. Hover over Coupon, then from the next submenu, click on New Entry.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-coupon.png)

3. A page will open. Enter the required coupon details.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-coupon-2.png)
    
4. Click on Save to add the new coupon.
