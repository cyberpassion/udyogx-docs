# Report

**Follow these steps to Get Consultation Report**

1.  Log into the Software
2.  Hover on "Consultation" module visible on the left sidebar menu.
3.  Click on “Consultation Report” submenu that appears.
4.  In the form that appears, Apply filters accordingly like “Consultation With”, “Select Date”, “Sort Result By”, “Mode”
5.  Click on “View Report” button to view the Consultation.

By following these steps, you will successfully get the report of Consultations in the Consultation module.
