# Settings

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Consultation > Settings'. 

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Consultation-Settings-1.png)

2.  Make changes as required and then click on 'Save' button at the bottom.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Consultation-Settings-2.png)
