# Add Consultation

## Stepwise Guide

**Follow these steps to Add New Consultation**

1.  Log into the Software
2.  Hover on "Consultation" module visible on the left sidebar menu.
3.  Click on “Add New Consultation” submenu that appears.
4.  In the form that appears, Fill necessary information like “Doctor Name”, “Fee”, “Time”, “Consultation For”, “Patient Name”, “Phone Number”, “Age”, “Gender”, “Guardian”, “Address”, “Mode” ,“Next Visit After”, “Referred By”, “Referred To”, “Remark (if any)”.
5.  Click on “Save” button to save the Consultation.
6.  A confirmation box will appear about the saved consultation successfully.

By following these steps, you will successfully created a new Consultation in the Consultation module.
