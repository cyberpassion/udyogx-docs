# Update Consultation

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Consultation > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Consultation-List.png)

2.  In the list, find the Exam , and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Consultation > Edit'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Update-Consultation.png)
    
4.  The entry page will open where you can make changes.
5.  After making the changes click on 'Save' button at the bottom.
6.  A confirmation modal would appear on successful submission.
