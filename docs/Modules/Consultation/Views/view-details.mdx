# View Details

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Consultation > View List'.
  
    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Consultation-List.png)
2.  In the list, find the the consultation, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Consultation > View Details'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Consultation-View-Details.png)
    
4.  The details will appear on the page.
