# Update Registration

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Registration > View List'.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Registration-List.png)

2.  In the list, find the registration , and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Registration > Edit'.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Update-Registration.png)
    
4.  The entry page will open where you can make changes.
5.  After making the changes click on 'Save' button at the bottom.
6.  A confirmation modal would appear on successful submission.
