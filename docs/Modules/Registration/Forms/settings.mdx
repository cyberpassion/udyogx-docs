# Settings

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Registration > Settings’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Registration-Settings-1.png)

2.  Choose the settings as per your needs and click on 'Save'
    | S.No | Setting Name                         | Description |
    |------|--------------------------------------|-------------|
    | 1    | Registration Types                   | Please list different types of registration types separated by comma.If you're using the module in an institute, registration types could be classes of admission for which students can register. If it's used in a clinic, it could be Consultation, Urgent Checkup, and so on. |
    | 2    | Registration Fee Slip Copies?        | How many copies of the registration slip should be visible when printing. |
    | 3    | Columns in Report                    | Please list here, separated by commas, the columns that should be displayed in the consultation report. |
    | 4    | Registration Fee to Take             | Select 'Yes' or 'No' whether to charge at the time of registration. |
    | 5    | Amount\*                             | Registration fee amount that is to be paid when doing registration. |
    | 9    | Is Public Registration Allowed\*     | (No description provided — please add if needed.) |
    | 10   | Default Public Registration Behaviour\* | (No description provided — please add if needed.) |
    | 11   | Default Public Registration Status\* | (No description provided — please add if needed.) |
    | 12   | Default Public Registration Amount\* | (No description provided — please add if needed.) |
