# View Profile

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Registration > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Registration-List.png)

2.  In the list, find the the registration, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Registration > Profile'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Registration-Profile.png)
    
4.  The profile details will appear on the page.
