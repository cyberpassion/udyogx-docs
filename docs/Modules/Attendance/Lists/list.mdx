# Attendance List

With udyogX you can easily view list an attendance. To do this first log in to the software entering your username and password.

## Stepwise Guide

1.  In the left sidebar menu, go to 'Attendance > View List'.  
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Atten.-LIST-1.png)

2.  Alternatively you can also search attendance in the searchbar at the top.
3.  In the list that appears, find the Attendance, and hover on the filter arrow located next to it.
4.  The view list will appear on the page.
