# View Details

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Sale > View List'.
2.  In the list, find the the saleservice, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Saleservice > View Details'
4.  The details will appear on the page.
