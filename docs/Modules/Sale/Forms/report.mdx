# Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Sale > View Report’.
2.  A filter page will open. Select the 'Report Type', Select Date, Select Appearance then click 'View Report'.
3.  The report will now display on the screen.
4.  Click on 'Print' button or press CTRL+P to print the report.
