# Add Patient

**Follow these steps to Add New Patien****t**

1.  Log into the Software
2.  Hover on "Patient" module visible on the left sidebar menu.

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/How-To-Add-New-Patient-Step-2.png)
    
3.  Click on “Add New Patient” submenu that appears.
4.  In the form that appears, Fill necessary information like “Name”, “Aadhar No.”, “Religion”, “Age”, “Gender”, “Phone Number”, “Address”, “Marital Status”, “Nationality”, “Spouse Name”, “Father Name”, “Mother Name”, “Guardian”, “Height”, “Weight”, “Blood Pressure”, “Pulse Rate”, _Admission Details_ and _Discharge Details_.
5.  Click on “Save” button to save the Patient.![](https://learn.udyogx.in/wp-content/uploads/2022/06/How-To-Add-New-Patient-Step-5.png)
6.  A confirmation box will appear about the saved patient successfully.

By following these steps, you will successfully created a new Patient in the Patient module.
