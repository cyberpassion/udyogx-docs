# View History

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Leaves > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Leave-List.png)

2.  In the list, find the the leaveapplication, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Leaveapplication > View History'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Leave-View-History.png)
    
4.  The History will appear on the page.
