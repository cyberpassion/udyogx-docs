# Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Leave Application > View Report’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Leave-Report-1.png)

2.  A filter page will open. Select the desired filters from the given options and click 'View Report'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Leave-Report-2.png)

3.  The report will now be displayed on the page.
