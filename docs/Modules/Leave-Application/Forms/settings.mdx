# Settings

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Leaveapplication > Settings’.
2.  On the settings page, adjust the settings as per your requirement and click on 'Save'

| S.No | Setting Name                                 | Description |
|------|----------------------------------------------|-------------|
| 1    | Leave Application Allowed to Student         | Leave application for students to choose whether to allow or not |
| 2    | Leave Application Allowed to Employee        | Select whether to allow leave application for employee |
| 3    | Half Day Allowed (Master)                    | Half day leave is allowed |
| 4    | Half Day Allowed to Student                  | Half day leave is allowed |
| 5    | Half Day Allowed to Employee                 | Half day leave is allowed |
| 6    | Info Columns in Leave Application Report\*   | Please list the names of the columns you need in the report, separated by commas. |
| 7    | Document Uploads\*                           | You have to mention the name of the document while applying for leave. |
| 8    | Send Leave Application Notification SMS to HR/Admin? | Whether to send the Application Quit Notification SMS to HR/Admin, select here. |
| 9    | SMS Template ID                              | Enter the template ID of the SMS to be sent |
| 10   | Send Leave Application SMS to Applicant?     | Employee has to choose whether to send notification of leave application or not |
| 11   | SMS Template ID                              | Enter the template ID of the SMS to be sent |
| 12   | HR Response SMS Template ID                  | Enter the template ID of the SMS to be sent |
| 13   | HR Response SMS Template to Applicant        | Yes, the SMS to be sent will be entered |
