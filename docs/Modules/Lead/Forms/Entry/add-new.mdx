# Add Lead

## Stepwise Guide

**Follow these steps to Create New Lead** 

1.  Log into the software.
2.  Hover on "Lead " module visible on the left sidebar menu.

   ![](https://learn.udyogx.in/wp-content/uploads/2022/06/How-to-Add-New-Lead-Step-1.png)

3.  Click on "Add New" submenu that appears.

   ![](https://learn.udyogx.in/wp-content/uploads/2022/06/How-to-Add-New-Lead-Step-1-1.png)
   
4.  In the form that appears, fill the necessary details like “Lead Gen By”, ”Activity”, ”Client Name”, “Client Email”, “Client Address”, “Product”, “Contact Person”, “Mobile No.”, “Website Link”, “Reference”, Enter any “Comment” about the lead, Select date for “Next Contact On”.
5.  Click on ‘Save’ button at the bottom.![](https://learn.udyogx.in/wp-content/uploads/2022/06/How-to-Add-New-Lead-Step-5-1024x501.png)
6.  A confirmation box will appear when the details are saved successfully.

By following these steps, you will successfully create a new lead in the Lead module.
