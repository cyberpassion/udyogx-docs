# Send Email

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Communication > Email > Send E-Mail’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Send-Email.png)

2.  The page will open where you can select the E-Mail recipient. Choose the person you want to send the message to.
3.  A page will open where you can select the class and section of the student. Choose the class and click 'Refresh List.'
4.  A list of students will appear on the right. Select the student to whom you wish to send the message.
5.  Now click on 'Load Templates' and a list of message templates will show on the page.
6.  Select the template that you wish to use and click on 'Select'
7.  Click on 'Send' to send the message to selected Recipient's.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Send-Email-2-1.png)

8.  A confirmation modal would appear on successful submission.
