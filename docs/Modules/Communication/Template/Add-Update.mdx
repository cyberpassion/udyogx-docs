# Add/Update Template

## Stepwise Guide to Add Template

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Communication > Template > Add New’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-communication.png)

2.  A page will open where you can select the Is Active and Name for the user entry, fill template name and content field.
3.  Click on 'Save' button.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-communication-2.png)
    
4.  A confirmation modal would appear on successful submission.

## Stepwise Guide to Update Template

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Communication > Template > View List’.

     ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-communication.png)

2.  A page will open, on the right side hover over the arrow icon, then hover on communication and click on Edit.

     ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-communication-2.png)

2.  A page will open where you can select the Is Active and Name for the user entry, fill template name and content field.
3.  Click on 'Save' button.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-communication-3.png)
    
4.  A confirmation modal would appear on successful submission.
