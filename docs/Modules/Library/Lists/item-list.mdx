# Library Item List

With udyogX you can easily view list an Library items list. To do this first log in to the software entering your username and password.

## Stepwise Guide

1. In the left sidebar menu, go to ‘Library > List > Items List’.

   ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Library-List.png) 
   
2. Alternatively you can also search library in the searchbar at the top.
3. In the list that appears, find the Library, and hover on the filter arrow located next to it.
4. The view list will appear on the page.
