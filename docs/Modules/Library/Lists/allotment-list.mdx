# Library Allotment  List

With udyogX you can easily view list an library allotment list. To do this first log in to the software entering your username and password.

## Stepwise Guide

1. In the left sidebar menu, go to ‘Library > Allotment > Allotment List’’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/library-allotment-list.png)
    
2. Alternatively you can also search library in the searchbar at the top.
3. In the list that appears, find the Library, and hover on the filter arrow located next to it.
4. The view list will appear on the page.
