# Stock Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Library > Stock Report’.
2.  Choose the ‘Entity Type’, ‘Language’, ‘Publication’ and ‘Supplier’ and click on ‘View Report’
3.  The report page will now open with the details of all the books and their quantity
4.  You can print the report by clicking on the print button or pressing CTRL+P
