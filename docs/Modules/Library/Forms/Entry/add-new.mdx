# Add Library

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Library > Add New > Add Item'.
2.  A form will open where you have to enter the book's details.
3.  Fill the necessary details such as 'Quantity', 'Accession Number', 'ISBN', 'Publication', 'Item Name' and others. Fields marked \* are compulsory.
4.  Once all the details are filled in, click the 'Save' button at the bottom.
5.  A confirmation modal would appear on successful submission.
