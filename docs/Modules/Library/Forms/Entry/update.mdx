# Update Library

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Library >List > Items List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Library-List.png)

2.  In the list, find the book's , and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Library > Update'.
4.  The entry page will open where you can make changes.
5.  After making the changes click on 'Save' button at the bottom.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Update-Library.png)
    
6.  A confirmation modal would appear on successful submission.
