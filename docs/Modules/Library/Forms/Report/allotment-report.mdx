# Allotment Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Library > Report > Allotment Report’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Allotment-Report-1.png)

2.  Choose the ‘Entity Type’, ‘Report Type’, ‘Session’, ‘Class’, ‘Section’ and ‘Appearance’ and click on ‘View Report’
    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Allotment-Report-2.png)

3.  The report page will now open with the details of all the allotment books and their quantity
4.  You can print the report by clicking on the print button or pressing CTRL+P

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Allotment-Report-3.png)
