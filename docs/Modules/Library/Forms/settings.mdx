# Settings

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Library > Settings'.
2.  Adjust the settings as per your requirements and click 'Save'.

| S.No | Setting Name                        | Description |
|------|-------------------------------------|-------------|
| 1    | Send Book Allotment Notification SMS | Whether to send SMS notification. Yes/No — Select whether to send Yes |
| 2    | Template ID                         | Enter the template ID of the SMS to be sent |
| 3    | Template                            | Please enter the SMS you want to send here. |
| 4    | Send Book Return Notification SMS   | Would you like to send an SMS notification? Yes or No |
| 5    | Template ID                         | Enter the template ID of the SMS to be sent |
| 6    | Template                            | Yes, the SMS to be sent will be entered |
