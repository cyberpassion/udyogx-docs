# View History

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Library > List > Items List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Library-List.png)

2.  In the list, find the book's name, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Library > View History'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Library-History-1.png)
    
4.  The History will appear on the page.
    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Library-History-2-1.png)
