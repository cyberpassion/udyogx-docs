# Allotment Report

You can view allotment report easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Library. A submenu will appear. Hover over Report, then click on Allotment Report.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/allotment-report.png)

3. A page will open. Apply the required filters and click on View Report.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/allotment-report-2.png)
