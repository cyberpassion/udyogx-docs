# How to set in Penalty 

You can update penalty settings easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Library. A submenu will appear. Hover over Settings, then click on Penalty Settings.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/set-penalty.png)

3. A page will open. Enter the penalty name and value, then click on Save.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/set-penalty-2.png)
