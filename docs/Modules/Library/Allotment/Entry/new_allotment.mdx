# New Allotment

You can create new allotment easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Library. A submenu will appear. Hover over Allotment, then from the next submenu, click on New Allotment.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/new-allotment.png)

3. A page will open showing different types of allotments such as Student, Employee, Consultation, etc. Select the appropriate option as per your requirement (e.g., Student).

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/new-allotment-2.png)

4. A new page will open. Enter the allotment details and click on Do Allotment.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/new-allotment-3.png)
