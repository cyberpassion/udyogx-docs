# View Results

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Exam > Employee List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Examresult-List.png)

2.  In the list, find the the examresult, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Examresult > View Results'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/View-Examresult.png)
    
4.  The result details will appear on the page.
