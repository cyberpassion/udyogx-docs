# Settings

# Stepwise Guide

Log in to the software entering your username and password.

1.  Go to "Settings" in Exam

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Examresult-Settings-1.png)

2.  Make Changes as per your Requirement
3.  Click on "Save"

    | S.No | Setting Name                          | Description                                                                 |
    |------|---------------------------------------|-----------------------------------------------------------------------------|
    | 1    | Send Book Allotment Notification SMS  | To send a book allotment notification, you need to click 'yes' or 'no' below to send the SMS |
    | 2    | Template ID                           | Enter the template ID of the SMS to be sent                                |
    | 3    | Template                              | Please enter the SMS you want to send to the client here                   |
    | 4    | Send Book Return Notification SMS     | Please write the SMS notification you want to send for book return here    |
    | 5    | Template ID                           | Enter the template ID of the SMS to be sent                                |
    | 6    | Template                              | Please enter the SMS you want to send to the client here                   |

    ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Examresult-Settings-2.png)
