# Add Examresult

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Exam > Create New ’.

    ![]( https://learn.udyogx.in/wp-content/uploads/2025/07/Add-Examresult-1.png)

2.  An Examresult entry page will be open.
3.  Complete the Result Details and Result Structure Form.
4.  Click on 'Create Exam' button.

    ![]( https://learn.udyogx.in/wp-content/uploads/2025/07/Add-Examresult-2.png)
    
5.  A confirmation modal would appear on Exam Created.
