# Examresult List

With udyogX you can easily view list an exam result. To do this first log in to the software entering your username and password.

## Stepwise Guide

1. In the left sidebar menu, go to ‘Exam > View Result List’.

   ![](https://learn.udyogx.in/wp-content/uploads/2025/07/Examresult-List.png)
   
2. Alternatively you can also search examresult in the searchbar at the top.
3. In the list that appears, find the Examresult, and hover on the filter arrow located next to it.
4. The view result list will appear on the page.
