# Settings

| S.No | Setting Name                          | Description |
|------|----------------------------------------|-------------|
| 1    | Default Questions*                     | How many questions are given in the test and whose value is given? |
| 2    | Default Duration*                      | How many hours or minutes the test is to be put here |
| 3    | Default Start Time*                    | What time does the test start |
| 4    | Default Max Attempts*                  | The number of times a student can attempt a test is to be entered here |
| 5    | Display Instant Result?                | Only bad results of the test are being shown or not, that has to be entered here. |
| 6    | Multi-Language Option for Test?        | Online tests are conducted in many languages such as Hindi, English, and Sanskrit. You need to select here which language you want to take the test in, by clicking 'yes' or 'no' on the options provided below |
| 7    | Test Formats*                          | The test format can vary, but currently, only multiple-choice questions are available. |
| 8    | Test Packages*                         | We can make a package by grouping the test, which we can then sell by setting the pricing, here you will enter the name of your package. |
| 9    | Test Coupon Codes*                     | You can enter the coupon code provided for the test here |
| 10   | Test Categories*                       | Test categories, every test that is created is assigned to one or the other category. You may enter new categories here separated by a comma. |
| 11   | Test Tags*                             |  |
| 12   | Test Marking Format*                   | What is the format of marking the test? |
| 13   | Minutes Warning before Test End?*      | How many minutes before the end of the test, the students have to be informed, that time will be put here |
| 14   | Student Info Columns in Test Report*   | It is written in the report that his entry will be here |
| 15   | Send Test Reminder SMS                 | Select whether to send test reminder SMS or not |
| 16   | Template ID                            | Enter the template ID of the SMS to be sent |
| 17   | Template                               | Yes the SMS to be sent will be entered |
