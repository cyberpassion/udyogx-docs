# Update Test

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Online Test >Single Test> View List'.
2.  In the list, find the test , and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Test > Edit'.
4.  The entry page will open where you can make changes.
5.  After making the changes click on 'Save Test' button at the bottom.
6.  A confirmation modal would appear on successful submission.
