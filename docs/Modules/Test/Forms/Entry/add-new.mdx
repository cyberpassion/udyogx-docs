# Add Test

## Stepwise Guide

Log in to the software entering your username and password. 1.In the left sidebar menu, go to 'Test >Single Test > Create New'. ![](https://learn.udyogx.in/wp-content/uploads/2025/04/2-5.png) 
2.A form will open where you can fill in the details of the test, such as the 'Pattern', 'Class', 'Date', 'Timing', and 'Duration'. ![](https://learn.udyogx.in/wp-content/uploads/2025/04/3-5.png) 
3.After filling in all the details, click 'Save Test'. ![](https://learn.udyogx.in/wp-content/uploads/2025/04/4-5.png) 
4.A confirmation modal would appear on successful submission.
