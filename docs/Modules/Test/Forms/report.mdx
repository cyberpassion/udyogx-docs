# Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Online Test >Single Test > View Report’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/test-report.png)

2.  A filter page will open. Select the 'Test', Report Type, Sort By, Appearance then click 'View Report'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/test-report-2.png)
    
3.  The report will now display on the screen.
4.  Click on 'Print' button or press CTRL+P to print the report.
