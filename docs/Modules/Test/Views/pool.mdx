# View Pool

You can view pool easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Online Test. A submenu will appear. Click on Pool.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/view-pool.png)
    
3. The list of pools will be displayed.
