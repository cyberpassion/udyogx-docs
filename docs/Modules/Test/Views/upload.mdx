# Upload Questions

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Online Test > Single Test > View List’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-test-3.png)

2.  In the list, find the test, and click on the filter arrow located next to it.
3.  In the dropdown menu go to 'Test > Upload Questions'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/upload-questions.png)

4.  On the upload page, choose the document type from the top menu, then drag and drop your file into the designated area and click Upload.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/upload-questions-2.png)
    
5.  Your file will now be uploaded.
