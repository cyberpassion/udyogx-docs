# Package List

You can view package easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Online Test. A submenu will appear. Hover over Package, then from the next submenu, click on View List.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/package-list.png)
    
3. The list of packages will be displayed.
