# View Details

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Online Test > Single Test > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-test-3.png)

2.  In the list, find the the test, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Test > View Details'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/view-details-test.png)
    
4.  The details will appear on the page.
