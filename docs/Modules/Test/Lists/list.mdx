# Test List

With udyogX you can easily view list an test. To do this first log in to the software entering your username and password.

## Stepwise Guide

1. In the left sidebar menu, go to ‘Online Test > Single Test > View List’.
2. Alternatively you can also search test in the search bar at the top.
3. In the list that appears, find the Test, and hover on the filter arrow located next to it.
4. The view list will appear on the page.
