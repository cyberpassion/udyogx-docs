# View Report

You can view report easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Online Test. A submenu will appear. Hover over Package, then from the next submenu, click on View Report.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/view-report.png)

3. A page will open. Set the required filters and click on View Report.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/view-report-2.png)
    
4. The report will be displayed.
