# View Details

## Stepwise Guide

1.  Log in to the portal using your credentials.
2.  After logging in, the **Dashboard** page will appear.
3.  To view the list of any module, click on the respective module from the dashboard menu.
4.  Click on the **Student Module** to proceed.
5.  Inside the Student Module, click on **"View List"** to see all the students.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-List.png)

6.  In the list, find the Student , and hover on the filter arrow located next to it.
7.  A dropdown menu would appear. Select 'Student > View Details'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-View-Details.png)
    
8.  The view details page will open.
9.  The same process can be followed in any module to view details through the **View List** section.
