# Apply List Filters

### How to View List and Apply Filter  from the Dashboard

### 1. Login to the Portal
- Log in to the portal using your credentials.

### 2. Dashboard Opens
- After logging in, the **Dashboard** page will appear.

### 3. Accessing a Module
- To view the list of any module, click on the respective module from the dashboard menu.

### 4. Open the Student Module
- Click on the **Student Module** to proceed.

### 5. Click on "View List"
- Inside the Student Module, click on **"View List"** to see all the students.

### 6. Apply Filters
- At the top of the View List page, you can use the filter options:
  - **Session:** Select the academic session.
  - **Class:** Choose the desired class.
  - **Section:** Filter by student section.
  - **Source:** Filter by the source (e.g., walk-in, referral, online).
  - **Status:** Filter students based on status like:
    - `Active`
    - `Draft`
    - `Promoted`

### 7. View Customized List
- After setting the filters, the student list will be displayed as per your selected criteria.

### 8. Note
- The same process can be followed in any module to view and filter the list through the **View List** section.
