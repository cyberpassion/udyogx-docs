# Apply List Filters

### How to View List and Apply Filter  from the Dashboard

1. Log in to the portal using your credentials.
2. After logging in, the **Dashboard** page will appear.
3. To view the list of any module, click on the respective module from the dashboard menu.
4. Click on the **Student Module** to proceed.
5. Inside the Student Module, click on **"View List"** to see all the students.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-List.png)
    
6. At the top of the View List page, you can use the filter options:
      - **Session:** Select the academic session.
      - **Class:** Choose the desired class.
      - **Section:** Filter by student section.
      - **Source:** Filter by the source (e.g., walk-in, referral, online).
      - **Status:** Filter students based on status like:
        - `Active`
        - `Draft`
        - `Promoted`

7. After setting the filters, the student list will be displayed as per your selected criteria.
8. The same process can be followed in any module to view and filter the list through the **View List** section.
