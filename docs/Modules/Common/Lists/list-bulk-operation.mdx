# Bulk Operation List

## Stepwise Guide

Log in to the software entering your username and password.

1.  Log in to the portal using your credentials.
2.  After logging in, the **Dashboard** page will appear.
3.  To view the list of any module, click on the respective module from the dashboard menu.
4.  In the left sidebar menu, go to ‘Student > Bulk Operation’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Common-Bulk-Operation.png)

5.  The bulk operation page will open.
6.  Go to the **Operation Name** field.
7.  You will see a **dropdown menu** in this field.
8.  Click on the dropdown menu.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-Bulk-List-1.png)

9.  A list of all available **bulk operations** will be displayed.
10. The same process can be followed in any module to bulk operation list through the **Bulk Operation** section.
