# Upload Data

## Stepwise Guide

1.  Log in to the portal using your credentials.
2.  After logging in, the **Dashboard** page will appear.
3.  To view the list of any module, click on the respective module from the dashboard menu.
4.  In the left sidebar menu, go to 'Student > Add New' page.![](https://learn.udyogx.in/wp-content/uploads/2023/10/1.png)
5.  Click on the 'Upload Excel' button on the top right.![](https://learn.udyogx.in/wp-content/uploads/2023/10/2.png)
6.  There is an option to download sample file in the upload block. Click on it to download the sample file. ([Download Sample Excel File](https://docs.google.com/spreadsheets/d/1RBKV9wZDjkQg_2cyj12WwfQlGqS2MHrc/edit?usp=sharing&ouid=116151701074254072241&rtpof=true&sd=true))![](https://learn.udyogx.in/wp-content/uploads/2023/10/3.png)
7.  Whatever column names are there on the sample file, prepare your data and add them accordingly. You do not have to make any changes in the column names, you only have to add data and the data which is not available can be left blank.
8.  You must try to enter Student Name, Father Name, Current Class, Admission Class, Current Section, Admission Section, Current Session, Admission Session, Phone Number so that you can use the software properly. It would be difficult to use the software when there is incomplete data.
9.  The data of students of the entire institute will be added to the first sheet of excel. Software only picks data from the first sheet of excel and the rest of the sheets are not read. (Download Excel File with Sample Data)
10.  After preparing the data, you can upload excel (in option provided in Step 2).![](https://learn.udyogx.in/wp-content/uploads/2023/10/4.png)
11.  After successfully uploading the data, a confirmation will be shown and will start showing in the students list and reports.
     
     ![](https://learn.udyogx.in/wp-content/uploads/2023/10/5.png)
     
12.  The same process can be followed in any module to upload data through the **Add New** section.
