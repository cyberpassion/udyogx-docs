# Bulk Operation

## Stepwise Guide

Log in to the software entering your username and password.

1.  Log in to the portal using your credentials.
2.  After logging in, the **Dashboard** page will appear.
3.  To view the list of any module, click on the respective module from the dashboard menu.
4.  In the left sidebar menu, go to ‘Student > Bulk Operation’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Common-Bulk-Operation.png)

5.  Select the operation you want to do such as Promote all student, Demote all student or print any document of any Students.
6.  Select the students for whom you want to perform the action, and then click 'Process'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Common-bo-2.png)

7.  The action will now be performed.
8.  The same process can be followed in any module to bulk operation through the **Bulk Operation** section.
