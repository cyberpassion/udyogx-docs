# Update Common

## Stepwise Guide

1.  Log in to the portal using your credentials.
2.  After logging in, the **Dashboard** page will appear.
3.  To view the list of any module, click on the respective module from the dashboard menu.
4.  Click on the **Student Module** to proceed.
5.  Inside the Student Module, click on **"View List"** to see all the students.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-List.png)

6.  In the list, find the student’s name, and click on the filter arrow located next to it.
7.  Select the option “Update” from the dropdown menu.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-Update.png)
    
8.  In the “Update” section, make the necessary changes to the student’s name or any other details.
9.  After making the changes, click on “Save” to update the student’s details.
10. The same process can be followed in any module to Update entry through the **View List** section.
