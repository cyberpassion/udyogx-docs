# Add Common

## Stepwise Guide

1. Log in to the portal using your credentials.
2. After logging in, the **Dashboard** page will appear.
3. To view the list of any module, click on the respective module from the dashboard menu.
4. Click on the **Student Module** to proceed.
5. Inside the Student Module, click on **"Add New"** to see all the students.

   ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Common-Upload-Data-1Student.png)

3. A form will open where you have to enter student details.
4. Fill the necessary details such as 'Student Name', 'Admission Class', 'Phone Number', 'Email', 'Fathers Name' and others. Fields marked \* are compulsory.
5. After entering the details click on 'Save' at the bottom.
6. A confirmation modal would appear on successful submission.

   ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-Entry-Save.png)

7. The same process can be followed in any module to add  new entry through the **Add New** section.
