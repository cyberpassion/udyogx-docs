# Report

## Stepwise Guide

1. Log in to the portal using your credentials.
2. After logging in, the **Dashboard** page will appear.
3. To view the list of any module, click on the respective module from the dashboard menu.
4. Click on the **Student Module** to proceed.
5. Inside the Student Module, click on **"Student List Report"** to see all the students.
   
   ![](https://learn.udyogx.in/wp-content/uploads/2022/06/Screenshot-07-27-2024-13.33.03-300x150.png)

6.  Select the session and type of report you want. You can also choose specific filters as per your requirement
7.  For more filters you can click on 'Show More Filters' at the bottom
8.  From the list on the right, please choose the details you wish to include in your report.![](https://learn.udyogx.in/wp-content/uploads/2022/06/Screenshot-07-27-2024-13.36.02-300x150.png)
9.  Click on 'View Report' after selecting the filters
10. The student report will appear on the page. You can print the report by clicking on Print button or CTRL+P
11. The same process can be followed in any module to view report through the **Student List Report** section.
