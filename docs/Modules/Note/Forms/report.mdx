# Report

## Stepwise Guide

1.  Log in to the software using your username and password.
2.  In the left sidebar menu, go to ‘Note > View Report’.

   ![](https://learn.udyogx.in/wp-content/uploads/2022/11/Note-View-Report-300x200.png)
   
3.  Choose the filters from the available options and click 'View Report'.
4.  The report will be displayed on the page.
