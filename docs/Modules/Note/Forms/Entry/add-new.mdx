# Add Note

## Stepwise Guide

1.  Log in to the software using your username and password.
2.  Navigate to the list of any module by clicking on the 'View List' option in the left sidebar menu. ![](https://learn.udyogx.in/wp-content/uploads/2022/11/Untitled-design-18.png)
3.  In the list, find the name of the student/employee/patient/customer, and hover over the filter arrow next to it.
4.  In the dropdown menu, select the '+Note' option.
5.  A popup will appear with a text area. Type your note in the text area and click 'Save'.
