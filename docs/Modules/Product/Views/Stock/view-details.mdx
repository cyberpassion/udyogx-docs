# View Details

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Product >Stock > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/stock-list.png)

2.  In the list, find the the student, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Stock > View Details'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/view-details-1.png)
    
4.  The details will appear on the page.
