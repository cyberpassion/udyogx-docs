# View Details

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Product > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Product-List.png)

2.  In the list, find the the product, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Product > View Details'
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Product-View-Details-1.png)

4.  The details will appear on the page.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/Product-View-Details-2.png)
