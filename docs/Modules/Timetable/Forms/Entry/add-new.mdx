# Add Timetable

Follow these steps to Create New Timetable in UdyogX.

## Stepwise Guide

1.  Login into the Software using Username and Password.
2.  Hover of “Time Table” module visible on left sidebar menu.
3.  In the submenu that appear click on “Create New”.

  ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-timetable.png)

4.  An Entry page will open Select/Fill the all required information.
5.  Click on "View Timetable".

  ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-timetable-2.png)

6.  Teacher Allotment page will open.
7.  Click on time and then select teacher and then Click "Perform Allotment".
8.  Click on subject name to change.
9.  Double click to Select subjects.

  ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-timetable-3.png)
