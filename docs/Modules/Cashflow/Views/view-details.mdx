# View Details

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Cashflow > Expense/Income > View Expense List/View Income List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/upload-cashflow.png)

2.  In the list, find the the Cashflow, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Cashflow > View Details'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/08/view-details-cashflow.png)
    
4.  The details will appear on the page.
