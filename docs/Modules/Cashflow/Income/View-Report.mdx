# Income Report

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Cashflow > Income > Income Report'.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Income-Report.png)
    
2.  Select the 'Head', 'Type', 'Mode', 'Amount Limit' etc and click on 'View Report'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Income-Report-2.png)

3.  The report will now display on the page. Click the 'Print' button or press CTRL+P to print the report.
