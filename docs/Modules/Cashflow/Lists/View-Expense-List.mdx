# View Expense

With udyogX you can easily view list an expense. To do this first log in to the software entering your username and password.

## Stepwise Guide

1.  In the left sidebar menu, go to 'Expense > View Expense List'.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Expense-List.png)
    
2.  Alternatively you can also search expense in the searchbar at the top.
3.  In the list that appears, find the Expense, and hover on the filter arrow located next to it.
