# Report

**Follow these steps to View Report of Survey**

1.  Log into the Software
2.  Hover on "Survey" module visible on the left sidebar menu.
3.  Click on “View Report” submenu that appears.

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/Surver-View-Report-300x200.png)

4.  In the form that appears, apply filters like “Category”, “Select Date”, “Status” accordingly.
5.  Click on “View Report” button in the form.

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/Surver-View-Report-page-300x200.png)

By following these steps, you will successfully View Report of a Survey in the Survey module.
