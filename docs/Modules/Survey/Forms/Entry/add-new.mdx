# Add Survey

**Follow these steps to Create Survey**

1.  Log into the Software
2.  Hover on "Survey" module visible on the left sidebar menu.
3.  Click on “Add New” submenu that appears.

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/survey-300x200.png)

4.  In the form that appears, Fill necessary information like “Category”, “Date”, “Question”, “Options”, “Why Survey”.
5.  Select “Recipients” from right side of the form.
6.  Click on “Save” button to save the survey.

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/Survery-Entry-300x200.png)
    
7.  A confirmation box will appear about the saved survey successfully.

By following these steps, you will successfully created a new Survey in the Survey module.
