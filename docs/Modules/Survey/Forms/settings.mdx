# Settings

| S.No | Setting Name              | Description |
|------|---------------------------|-------------|
| 1    | Survey Categories         | Survey category refers to the type of survey you're conducting when making an entry. For example, you might be doing a school survey, staff survey, or staff room survey. These are categories that you can use to classify your survey entry. It helps organize the focus or topic of your survey. |
| 2    | Send Survey Notification SMS | "Send Survey notification SMS" means that if you want to send a notification via SMS or email when you're entering a survey, you'll need to select from the options provided below whether you want to send an SMS or not. |
| 3    | Template ID               | SMS which must be entered in your template place |
