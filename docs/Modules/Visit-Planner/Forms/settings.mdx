# Settings

| S.No | Setting Name                           | Description |
|------|----------------------------------------|-------------|
| 1    | Columns in Report*                     | If you have entered a new visit meeting entry in your visit management, after entering, if you want to see the list of all those visit meetings together and also want to see their remaining details, then there is a visit report. In this report, you can see all the details of the visit meeting entry at once, such as client name, visit entry date, client phone number, you can see all of these together. You need to enter the names of the visit planners you want details for, separated by commas. Example - visit date, Client name, Client Phone no |
| 2    | Default State*                         | When you meet with any client, we record the details in the visit planner. At the time of entry, there is an option to select the state. We have set the name of a particular state to be entered where we are making the entry. However, the name of the state already appears selected in the tab of the state, which we call (Default State). |
| 3    | Default Visit Start Time*              | If the sales team is visiting any school or college, they need to enter the time of their visit in the visit planner. When you enter the time, you should enter it according to the pre-set time, which we call the Default Visit Start Time. For example, if you scheduled a meeting at 3:00 PM, then enter the time as 3:00 PM. |
| 4    | Send New Visit Planner Notification SMS| Whenever you enter a new visit meeting in the visit planner, an SMS will be sent for confirmation after the entry. You need to select either yes or no to confirm. |
| 5    | Template ID                            | The new visit planner SMS sent will have a template ID, which you need to enter here. |
| 6    | Template                               | When you make a new entry in the visit planner, a notification SMS with a note will be sent to both employees and admins after the entry is made. |
| 7    | Visit Planner Scheduled Visit SMS*     | Whenever a new visit meeting is scheduled for a salesperson or employee, an SMS will be sent for confirmation that the meeting has been scheduled. You need to select yes or no. |
| 8    | SMS Template ID*                       | Enter the template ID for the scheduled visit planner SMS. |
| 9    | SMS Template*                          | When a new entry is made in the visit planner, a notification SMS will be sent to both employees and admins. |
