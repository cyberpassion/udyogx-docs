# Update Visit Planner

**Follow these Steps to Create New Visit with Excel/CSV in UdyogX**

## Stepwise Guide

1.  Log into the software.
2.  Hover on "Visit Planner" module visible on the left sidebar menu.
3.  Click on "Add New" submenu that appears.

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/2024-09-14_15-13-46-300x150.png)
    
4.  In the form that appears, on the top right corner click on “Upload Excel”![](https://learn.udyogx.in/wp-content/uploads/2023/11/2024-09-14_15-21-54-300x150.png)
5.  A box will appear and download the “Sample File”.
6.  Open that file in excel and enter the fields like “Session”, ”Planner Schedule”, “Employee”, “Team Member”, “Organization Name”, “Organization Type”, “State”, “Address”, “Meeting With”, “Visit Reason”, “Email”, “Phone Number”, “Website” , “Product”.
7.  Save that Excel file and follow the steps 2, 3, 4.
8.  This time Click on “Choose file”.
9.  Select the file from the dialog box that appears.
10.  Click on ‘Upload’ button.
11.  A confirmation box will appear about the file uploaded successfully.

By following these steps, you will successfully create a Visit with Excel/CSV in the Visit Planner module.
