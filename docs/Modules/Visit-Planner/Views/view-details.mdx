# View Details

## Stepwise Guide

1.  Log in to the software entering your username and password.
2.  In the left sidebar menu, go to 'Visit Planner > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-visit-planner.png)

3.  In the list, find the visitplanner , and hover on the filter arrow located next to it.
4.  A dropdown menu would appear. Select 'Visitplanner > View Details'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/visit-planner-view-details.png)
    
5.  The view details page will open.
