# Add Service

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Service > Add Service > View List’.![](https://learn.udyogx.in/wp-content/uploads/2022/06/Listing-New-Service-Step-1.png)
2.  A list will appear containing all the previous entries.
3.  In the list, find the service name and hover over the filter arrow next to it to access various options available in the dropdown menu.
