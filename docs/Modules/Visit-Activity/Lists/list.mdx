# Visitactivity List

With udyogX you can easily view list an visitactivity. To do this first log in to the software entering your username and password.

## Stepwise Guide

1. In the left sidebar menu, go to ‘Visit Report > View List’.
2. Alternatively you can also search visitactivity in the search bar at the top.
3. In the list that appears, find the Visitactivity, and hover on the filter arrow located next to it.
4. The view list will appear on the page.
