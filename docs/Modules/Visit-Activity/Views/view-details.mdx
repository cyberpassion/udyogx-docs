# View Details

## Stepwise Guide

1.  Log in to the software entering your username and password.
2.  In the left sidebar menu, go to 'Visit Report > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/visit-activity-list.png)

3.  In the list, find the visitactivity , and hover on the filter arrow located next to it.
4.  A dropdown menu would appear. Select 'Visitactivity > View Details'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/visit-activity-view-details.png)
    
5.  The view details page will open.
