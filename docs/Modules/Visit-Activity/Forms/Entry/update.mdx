# Update Visit Activity

## Stepwise Guide

1.  Login into the Software using Username and Password.
2.  Hover of "Visitactivity" module visible on left sidebar menu.
3.  In the submenu that appear click on "View List".

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/Visitactivity-ViewList-300x200.jpg)
    
4.  A list of all the Visit Activity will appear hover down arrow situated right side of every visit activity.
5.  In the submenu that appear hover of "Visitactivity" then in the another submenu select "Edit".![](https://learn.udyogx.in/wp-content/uploads/2022/06/Visitactivity-ViewList-Arrow-VisitActivity-Edit-300x200.png)
6.  A page will open for visit specifies select the "Visit Status" as "Visit Done".![](https://learn.udyogx.in/wp-content/uploads/2022/06/Visitactivity-ViewList-Edit-page-300x200.png)
7.  Option regarding to the visit will start to appears. Fill the necessary information marked with '\*'.
8.  In the right side of the bottom click on "Save" button to save the visit activity.![](https://learn.udyogx.in/wp-content/uploads/2022/06/Save-page-Visit-Activity-300x188.png)
9.  A dialog for comfirmation will appear after saving the visit activity.
