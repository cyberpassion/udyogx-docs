# Report

## Stepwise Instructions

1.  Login into the Software using Username and Password.
2.  Hover of “Visit Report” module visible on left sidebar menu.
3.  In the submenu that appear click on “View Report”.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/visit-activity-report.png)
    
4.  Fill/Select the required information and then click "View Report".

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/visit-activity-report-2.png)
