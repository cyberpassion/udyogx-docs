# Report

## Stepwise Instructions

1.  Login into the Software using Username and Password.
2.  Hover of “Visitactivity” module visible on left sidebar menu.
3.  In the submenu that appear click on “View Report”.

    ![](https://learn.udyogx.in/wp-content/uploads/2022/06/2024-09-14_15-44-12-300x150.png)
    
4.  Fill/Select the required information and then click "View Report".
