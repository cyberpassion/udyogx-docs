# Settings

| S.No | Setting Name                          | Description |
|------|----------------------------------------|-------------|
| 1    | Document Upload Types                  | In the Visit Activity, please list the names of the documents that the Sales Team can upload, separated by commas. |
| 2    | Competitors List                       | If the sales team has visited a college and that college is already using a product from another company, then the name of that company should be inserted here, separated by a comma. |
| 3    | Visit Region                           | The sales team is visiting which regions, for example - Agra, Mathura, Bhopal, etc. |
| 4    | Default Email Recipient                | You need to enter the email ID where you want the report of visit activity to be sent. |
| 5    | Email Recipient (Other)                | Besides the main email, we need to list the names of those who should receive the report of visit activity and other necessary mail IDs here, separated by commas. |
| 6    | Columns in Report                      | The entries for which columns should be present in the visit activity report will be listed here. |
| 7    | Send Visitactivity Email Copy          | Do you want us to send the email to clients? Please select here. |
| 8    | Send New Visit Planner Notification SMS| You need to send a notification at the time of Visit Planner's entry. Please select 'yes' or 'no' here to confirm. |
| 9    | Template ID                            | We need to input the template ID for the SMS we will send at the time of visit activity entry here. |
| 10   | Template                               | To send the notification SMS that will be sent at the time of visit planner. |
