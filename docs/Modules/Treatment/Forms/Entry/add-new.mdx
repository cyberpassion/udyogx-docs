# Add Treatment

## Stepwise Guide

**Follow these steps to Add New Treatment** 

1.  Log into the software.
2.  Hover on "Treatment " module visible on the left sidebar menu.
3.  Click on "Add New" submenu that appears.
4.  In the form that appears, fill the necessary details like “Recipient”, ”Date”, ”Observed By”, “Fee”, “Treatment Given”, “Remark”, “Observation”, “Status”.
5.  Click on ‘Save’ button at the bottom.

By following these steps, you will successfully add a new treatment in the Lead module.
