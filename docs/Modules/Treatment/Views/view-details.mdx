# View Details

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Treatment > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-treatment.png)

2.  In the list, find the the treatment, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Treatment > View Details'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/view-details-treament.png)
    
4.  The details will appear on the page.
