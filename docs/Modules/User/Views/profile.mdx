# View Profile

## Stepwise Guide

Log in to the software entering your username and password.

### 👤 Navigate to Add User 

1.  You will see the **User icon** on the top-right side.
2.  Click on the **User icon**.
3.  A dropdown menu will appear.
4.  Click on the **User List** option from the dropdown.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-user.png)

2.  In the list, find the the student, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'User > Profile'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/view-user-profile.png)
    
4.  The profile details will appear on the page.
