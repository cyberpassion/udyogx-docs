# View Details

## Stepwise Guide

Log in to the software entering your username and password.

### 👤 Navigate to Add User 

1.  You will see the **User icon** on the top-right side.
2.  Hover on the **User icon**.
3.  A dropdown menu will appear.
4.  Hover on **User**, a dropdown will appear, click on the **User List** option from the dropdown.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-user.png)

5.  In the list, find the student, and click on the filter arrow located next to it.
6.  In the dropdown menu go to 'User > View Details'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/user-view-details.png)

7.  The details will appear on the page.
