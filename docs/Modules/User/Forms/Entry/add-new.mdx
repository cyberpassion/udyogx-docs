# Add User

## Stepwise Guide

Log in to the software entering your username and password.

### 👤 Navigate to Add User 

1.  You will see the **User icon** on the top-right side.
2.  Click on the **User icon**.
3.  A dropdown menu will appear.
4.  Click on the **Create User** option from the dropdown.
4.  In the form that appears, fill the necessary details like “Select User Type”, ”User Name”, ”Password”, “User Mobile”, “User Email”.
5.  Click on ‘Save’ button at the bottom.

By following these steps, you will successfully create a new user in the User module.
