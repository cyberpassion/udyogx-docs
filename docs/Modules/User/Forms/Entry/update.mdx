# Update User

## Stepwise Guide

Log in to the software entering your username and password.

### 👤 Navigate to User List

1. You will see the **User icon** on the top-right side.
2. Hover on the **User icon**.
3. A dropdown menu will appear.
4. Hover on **User**, a dropdown will appear, click on the **User List** option from the dropdown.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-user.png)

5. In the list, find the student , and hover on the filter arrow located next to it.
6. A dropdown menu would appear. Select 'User > Edit'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-user-2.png)

7. The entry page will open where you can make changes.
8. After making the changes click on 'Save' button at the bottom.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-user-3.png)
    
9. A confirmation modal would appear on successful submission.
