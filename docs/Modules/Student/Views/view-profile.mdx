# View Profile

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Student > View List'.
    
    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-List.png)

2.  In the list, find the the student, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Student > view Profile'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-View-Profile.png)

4.  The profile details will appear on the page.
