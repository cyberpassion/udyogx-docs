# View Details

## Stepwise Guide

1.  Log in to the software entering your username and password.
2.  In the left sidebar menu, go to 'Student > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-List.png)

3.  In the list, find the Student , and hover on the filter arrow located next to it.
4.  A dropdown menu would appear. Select 'Student > View Details'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Student-View-Details.png)
    
5.  The view details page will open.
