# How to Change Fee Setting

You can change fee settings easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Student. A submenu will appear. Hover over Fee Settings, then from the next submenu, click on Fee Settings.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/change-fee-settings.png)

3. A page will open. Modify the required fields.
4. Click on Save to apply the changes.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/change-fee-settings-2.png)
