# How to add fee discount for single student

You can add fee discount for a single student easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Student. A submenu will appear. Click on View List.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-fee-discount.png)

3. A list of students will be displayed. For the student you want to add a discount to, hover over the arrow icon on the right. A submenu will appear. Hover over Fees, then from the next submenu, click on Add Discount.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-fee-discount-2.png)

4. A page will open. Enter the fee discount rule and click on Save Fee Rule.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/add-fee-discount-3.png)
    
5. The discount will be added for that student.
