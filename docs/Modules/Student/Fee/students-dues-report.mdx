# How to Check Students Dues Report

You can see students dues report easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2. On the left sidebar, hover over Student. A dropdown will appear. Hover over Report, then from the submenu, click on Dues Report.
3. A page will open. Apply the report filters as needed.
4. Click on View Report to generate the dues report.
