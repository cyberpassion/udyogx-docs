# Update Transport

You can update transport easily using UdyogX.

## Stepwise Guide

1. **Log in** to the software by entering your **username** and **password**.
2.  In the left sidebar menu, go to 'Transport > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-transport.png)

3.  In the list, find the transport , and hover on the filter arrow located next to it.
4.  A dropdown menu would appear. Select 'Transport > Edit'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-transport-2.png)

5.  The entry page will open where you can make changes.
6.  After making the changes click on 'Save' button at the bottom.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-transport-3.png)
    
7.  A confirmation modal would appear on successful submission.
