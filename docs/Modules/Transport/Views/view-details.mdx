# View Details

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Transport > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/update-transport.png)

2.  In the list, find the the transport, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Transport > View Details'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/09/transport-view-details.png)

4.  The details will appear on the page.
