# Add Booking

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Booking > Perform Booking’.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Add-booking.png)

2.  A page will open where you can select the building. Choose the building in which you want to perform the booking.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Booking-entry.png)

3.  An entry page will open. Select the booking type, check-in date, and expected check-out date.
4.  All the available rooms will now be displayed on the screen. Select the room you want to allot.
5.  Now, from the list on the right, choose the customer to whom you're allotting the room.
6.  If you wish to add new customer then click on 'Add Customer'.
7.  A popup form will open. Enter the customer's details and click 'Save'.
8.  Now the new customer will show in the list. Select the customer and click on 'Perform Booking'.
9.  The Booking will now be performed.
