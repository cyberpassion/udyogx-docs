# View Building

With udyogX you can easily view Building list. To do this first log in to the software entering your username and password.

## Stepwise Guide

1.  In the left sidebar menu, go to 'Booking > View Building List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Building-List.png)
    
2.  Alternatively you can also search booking in the searchbar at the top.
3.  In the list that appears, find the booking, and hover on the filter arrow located next to it.

Alternatively you can also do a search and follow the same steps on the search results that appear.
