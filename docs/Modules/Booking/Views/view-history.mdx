# History

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to ‘Booking > View Booking List’.
2.  In the list, find the booking, and click on the filter arrow located next to it.
3.  In the dropdown menu go to 'Booking > View History'
4.  The history will appear on the page. You can print it by clicking on the print button or pressing CTRL+P
