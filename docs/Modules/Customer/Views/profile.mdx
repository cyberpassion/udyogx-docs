# View Profile

## Stepwise Guide

Log in to the software entering your username and password.

1.  In the left sidebar menu, go to 'Customer > View List'.

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Customer-list.png)
    
2.  In the list, find the the customer, and hover on the filter arrow located next to it.
3.  A dropdown menu would appear. Select 'Customer > Profile'

    ![](https://learn.udyogx.in/wp-content/uploads/2025/06/Customer-View-Profile.png)

4.  The profile details will appear on the page.
